# Amnesia: The Dark Descent Ч Custom Stories & Mods Analysis

## ?? Overview
An exploratory data analysis (EDA) of user-generated content (custom stories and full conversion mods) for *Amnesia: The Dark Descent*. 
The goal of this project is to analyze community activity trends, content metrics, and factors affecting mod popularity (downloads).

## ?? Current Status & Key Insights (WIP)
*This project is currently Work In Progress (WIP). Data cleaning, preprocessing, and preliminary analysis are completed.*

### Key Insights to Date:
1. **Viral Peak (2012):** The peak of custom story creation occurred in 2012, likely driven by the viral popularity of *Amnesia* Let's Plays (e.g., PewDiePie).
2. **File Size Disparity:** A typical Custom Story averages **~10.53 MB** (archived), whereas a Full Conversion mod averages **~307.34 MB**.
3. **Map Count:** Despite the relatively large file size, a typical Custom Story consists of only **3 maps** on average.
